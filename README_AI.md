# Алгоритм 2: ИИ-расстановка вышек — как установить и обучить

> Файлы Алгоритма 2 уже встроены в проект — шаг 1 ниже нужен только при установке в чистую копию.

Нейросеть написана на чистом **numpy**: PyTorch, ONNX и видеокарта не нужны.
Работает на Windows с Python 3.12–3.14 в том же окружении, где запускается ZoneOneM.

## 1. Положить файлы в проект

Скопируйте файлы из этой папки в корень проекта `ZoneOneM` с той же структурой
(существующий `algorithms/auto_placement.py` заменяется):

| Файл | Что это |
| --- | --- |
| `algorithms/ai_model.py` | Нейросеть (прямой и обратный проход, оптимизатор Adam) |
| `algorithms/ai_placement.py` | Признаки участка, точная проверка покрытия, цикл расстановки |
| `algorithms/auto_placement.py` | «Алгоритм 2» подключён вместо заглушки |
| `tools/make_dataset.py` | Генерация обучающих примеров |
| `tools/train_ai.py` | Обучение с учителем + дообучение с подкреплением (RL) |
| `tools/compare_ai.py` | Сравнение с Алгоритмом 1 для отчёта |
| `tests/test_ai_placement.py` | Тесты |

Пока модель не обучена, «Алгоритм 2» в программе просто запускает Алгоритм 1 —
кнопка не падает.

## 2. Обучить модель (команды в PowerShell из папки ZoneOneM)

```powershell
cd путь\к\ZoneOneM

# 0) В архиве уже есть пробная модель models\ai_surrogate.npz (1500 участков, 12 эпох) —
#    «Алгоритм 2» работает сразу. Шаги ниже обучают модель получше.

# 1) Проверка, что всё работает (~2–3 минуты)
python tools\make_dataset.py --scenes 200 --out models\dataset_small.npz
python tools\train_ai.py --data models\dataset_small.npz --epochs 3

# 2) Полноценный датасет (на 4 ядрах ~20 мин; число процессов = ядер минус одно)
python tools\make_dataset.py --scenes 5000

# 3) Обучение с учителем (~4 мин на эпоху при 5000 участках, всего ~2 ч)
python tools\train_ai.py --epochs 30

# 4) Дообучение с подкреплением (RL), по желанию (~1 с на эпизод)
python tools\train_ai.py --init models\ai_surrogate.npz --epochs 0 --rl-episodes 300

# 5) Таблица для отчёта: ИИ против Алгоритма 1 на новых участках
python tools\compare_ai.py --scenes 10
```

Времена замерены на 4-ядерном Linux-сервере; на вашем ПК могут отличаться.

После шага 3 появляется файл `models\ai_surrogate.npz` (около 100 КБ). Программа
подхватывает его сама: запустите `python main.py`, нарисуйте участок и выберите
«Алгоритм 2 (ИИ: нейросеть + проверка)».

Во время обучения после каждой эпохи печатаются метрики на проверочных участках:

- **Спирмен** — насколько верно сеть упорядочивает точки по выгодности (1,0 — идеально);
- **top-8** — как часто лучшая по физике точка попадает в 8 кандидатов сети.

Лучшая по ним эпоха сохраняется автоматически.

## 3. Тесты

```powershell
python -m unittest tests.test_ai_placement
```

## Если что-то пошло не так

- `ModuleNotFoundError: ai_placement` — файлы лежат не в тех папках (см. таблицу выше).
- Генерация идёт медленно — уменьшите `--scenes` или увеличьте `--workers`.
- На Windows генерация в несколько процессов запускается только из командной строки
  (`python tools\make_dataset.py`), а не из IDLE.

## Что показал пробный прогон

Пробная модель (1500 участков, 12 эпох): Спирмен 0,45, top-8 — 53% на проверочных
участках. На 10 новых участках (`tools\compare_ai.py --scenes 10`): Алгоритм 1 — 96,7%
покрытия в среднем, ИИ — 95,6% при том же числе вышек (3,4). На 7 участках из 10 результат
одинаковый, на 3 ИИ хуже на 1–7 п.п. На этих небольших участках ИИ медленнее
(2,4 с против 1,1 с), потому что проверяет 14 кандидатов, а для секторных антенн —
ещё и все азимуты. Больше данных и эпох (шаги 2–4) должны сократить разрыв.
